# Digital Theological Exhibition

## Overview
A Next.js application presenting "The Image of God in the Book of Job" as an interactive digital exhibition.

## Local Development

The project is currently running. You can access it at:
**[http://localhost:3001](http://localhost:3001)**

> **Note**: Port 3001 is used because 3000 was detected as busy using process isolation.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Fonts**: Playfair Display (Heading) & EB Garamond (Body) - fully supporting Vietnamese.

## Recent Updates
- **Comparison Table**: Validated and styled "Table 1: Satan's Role" in Chapter 2.
- **Typography**: Switched to Playfair Display for better Vietnamese diacritics support.
- **Navigation**: Drawer menu for mobile.

## Features
- **Academics**: Justified typography, APA-style References, Comparison Tables.
- **Navigation**: Sticky Table of Contents (Desktop) & Drawer Menu (Mobile).
- **Interactive**: Parallax Hero, Theological Gloss (Tooltips).
